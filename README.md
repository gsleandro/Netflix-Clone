# Interface de login inspirada na Netflix

Projeto acadêmico de front-end que reproduz visualmente uma tela de login inspirada na Netflix.

## Objetivo

Praticar estruturação de páginas com HTML, estilização com CSS, formulários e organização de assets.

## Tecnologias

- HTML5
- CSS3
- Design responsivo

## Como visualizar

Clone o repositório e abra o arquivo `index.html` no navegador.

> Este projeto é apenas educacional e não possui vínculo com a Netflix. O formulário não realiza autenticação real.
